### 01 | Vero Scale
**Smart Food Scale with Built-In Nutrient Analysis**

Vero Scale is a smart embedded nutrition tracking device that combines real-time weight measurement with automated nutrient analysis to support diet monitoring and health tracking[cite: 2].

*Key Features:*
- **Precision Load Cell Interface:** Measures food weight accurately up to 5 kg via HX711 amplification[cite: 2].
- **Interactive Touchscreen Interface:** 2.4" TFT LCD (ILI9341 + XPT2046) touch display for smooth user navigation[cite: 2].
- **Nutrient Analysis & Logging:** Analyzes calories/macronutrients and logs food records directly onto a MicroSD card[cite: 2].
- **Calorie Limit Alerts:** Integrated active buzzer system that alerts users upon reaching daily calorie limits[cite: 2].
- **Portable Power Management:** Powered by an 18650 Li-ion battery with a TP4056 charging module and voltage regulator circuit[cite: 2].

* **Technologies:** `ESP32` • `C++` • `HX711` • `Load Cell` • `TFT Touchscreen` • `SPI/I2C` • `Embedded Systems`

### 02 | MediBox
**Smart Medication Reminder & Status Notification System**

MediBox is an ESP32-powered IoT medication alert system designed to help patients adhere to scheduled prescription regimens through multi-LED visual cues and audio alerts[cite: 1].

*Key Features:*
- **Multi-Stage LED Indicators:** Dedicated color-coded status LEDs (Power, Scheduled Medication Alerts, and System Status)[cite: 1].
- **Wireless Connectivity:** Integrated Wi-Fi status indicator for cloud sync and remote monitoring support[cite: 1].
- **Audible Alert System:** High-decibel piezo buzzer for immediate medication time warnings[cite: 1].
- **Microcontroller Integration:** GPIO pin-mapped hardware design driven by the ESP32 development board[cite: 1].

* **Technologies:** `ESP32` • `C++` • `IoT` • `Wi-Fi` • `GPIO Control` • `Embedded Electronics`
