A collection of software applications, engineering prototypes, and technical design projects.

### 01 | Vero Scale
**Smart Food Scale with Built-In Nutrient Analysis**

Vero Scale is a smart embedded nutrition tracking device that combines real-time weight measurement with automated nutrient analysis to support diet monitoring and health tracking[cite: 2].

*Key Features:*
- Precision load cell interface measuring food weight up to 5 kg using an HX711 amplifier module[cite: 2].
- Interactive 2.4" TFT LCD touchscreen display (ILI9341 + XPT2046) for clear system navigation[cite: 2].
- Nutrient database analysis and food record storage utilizing a MicroSD card module[cite: 2].
- Calorie limit tracking with an integrated buzzer alert mechanism[cite: 2].
- Portable 18650 Li-ion battery power supply managed via a TP4056 charging module and voltage regulator circuit[cite: 2].

* **Technologies:** `ESP32` • `C++` • `HX711` • `Load Cell` • `TFT Touchscreen` • `SPI/I2C` • `Embedded Systems`

### 02 | MediBox
**Smart Medication Reminder & Status Notification System**

MediBox is an ESP32-powered IoT medication alert system designed to help patients adhere to scheduled prescription regimens through multi-LED visual cues and audio alerts[cite: 1].

*Key Features:*
- Multi-stage color-coded LED indicators for power, scheduled medication notices, and Wi-Fi status tracking[cite: 1].
- Integrated Wi-Fi indicator tied to the ESP32 module for wireless synchronization[cite: 1].
- Audible piezo buzzer alert system for instant reminder notifications[cite: 1].
- Clean GPIO pin mapping and layout configured for microcontrollers[cite: 1].

* **Technologies:** `ESP32` • `C++` • `IoT` • `Wi-Fi` • `GPIO Control` • `Embedded Electronics`
